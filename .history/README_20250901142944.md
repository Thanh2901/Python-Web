# Togogo Backend Test – Django (Employees API)

Hướng dẫn cài đặt, chạy và test API quản lý nhân viên (Employees + WorkSchedule) bằng Django + Django REST Framework.

---

## 1. Yêu cầu

- Python >= 3.10
- pip
- virtualenv (tùy chọn)
- PostgreSQL (hoặc SQLite để chạy local)
- Git (nếu clone project)
- (Tùy chọn) Postman hoặc cURL để test API

---

## 2. Cài đặt môi trường

### 2.1 Clone project

```bash
git clone <link-repo-của-bạn>
cd <tên-folder>
```

### 2.2 Tạo virtual environment và kích hoạt

```bash
# Tạo virtualenv
python -m venv venv

# Kích hoạt trên Windows
venv\Scripts\activate

# Kích hoạt trên macOS/Linux
source venv/bin/activate
```

### 2.3 Cài đặt dependencies

```bash
pip install -r requirements.txt
```

---

## 3. Cấu hình Database

### 3.1 SQLite (mặc định)

Không cần thay đổi gì, Django sẽ tạo file `db.sqlite3`.

### 3.2 PostgreSQL (tùy chọn)

Tạo database và user:

```sql
CREATE DATABASE togogo_db;
CREATE USER togogo_user WITH PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE togogo_db TO togogo_user;
```

Trong `settings.py`:

```python
import os
from dotenv import load_dotenv
load_dotenv()

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': os.getenv("DB_NAME"),
        'USER': os.getenv("DB_USER"),
        'PASSWORD': os.getenv("DB_PASSWORD"),
        'HOST': os.getenv("DB_HOST"),
        'PORT': os.getenv("DB_PORT"),
    }
}
```

## 6. API Endpoints

### 6.1 Employees

| Method | URL                | Chức năng                    |
| ------ | ------------------ | ---------------------------- |
| GET    | `/employees/`      | Lấy danh sách nhân viên      |
| POST   | `/employees/`      | Tạo mới nhân viên            |
| GET    | `/employees/<id>/` | Lấy chi tiết 1 nhân viên     |
| PUT    | `/employees/<id>/` | Cập nhật thông tin nhân viên |
| DELETE | `/employees/<id>/` | Xóa nhân viên                |

**Payload tạo mới nhân viên** (POST `/employees/`):

```json
{
  "name": "Nguyen Van A",
  "email": "a@example.com",
  "position": "Developer",
  "department": "IT",
  "start_date": "2025-09-01"
}
```

### 6.2 WorkSchedule (Upsert)

| Method | URL                | Chức năng                            |
| ------ | ------------------ | ------------------------------------ |
| POST   | `/work_schedules/` | Thêm mới hoặc cập nhật lịch làm việc |

**Payload** (POST `/work_schedules/`):

```json
{
  "employee_id": 1,
  "work_day": "2025-09-01",
  "shift": "morning"
}
```

**Response ví dụ:**

```json
{
  "id": 1,
  "employee": 1,
  "work_day": "2025-09-01",
  "shift": "morning",
  "action": "created" // hoặc "updated"
}
```

## 7. Test API

### 7.1 Sử dụng cURL

**Tạo nhân viên:**

```bash
curl -X POST http://127.0.0.1:8000/employees/ \
-H "Content-Type: application/json" \
-d '{"name":"Nguyen Van A","email":"a@example.com","position":"Dev","department":"IT","start_date":"2025-09-01"}'
```

**Lấy danh sách nhân viên:**

```bash
curl http://127.0.0.1:8000/employees/
```

**Upsert WorkSchedule:**

```bash
curl -X POST http://127.0.0.1:8000/work_schedules/ \
-H "Content-Type: application/json" \
-d '{"employee_id":1,"work_day":"2025-09-01","shift":"morning"}'
```

### 7.2 Sử dụng Postman

1. Mở Postman → New Request
2. Chọn method (GET hoặc POST) và nhập URL:
   - `http://127.0.0.1:8000/employees/`
   - `http://127.0.0.1:8000/work_schedules/`
3. Chọn Body → raw → JSON và dán payload
4. Nhấn Send và xem kết quả JSON trả về
